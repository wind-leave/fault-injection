# 仿真组件故障槽位层级规则设计

## 背景

仿真组件的“故障设置”面板会列出可注入变量，并允许为每个变量选择物理层、电气层、协议层。当前界面默认对变量展示所有层级，容易把输入、输出信号误配置为物理层故障槽位。

## 目标

- 明确参数变量默认支持物理层注入。
- 输入参数和输出参数支持电气层、协议层注入。
- 输入参数和输出参数不支持物理层注入。
- 本次不处理中间量，保持当前中间量层级展示和保存行为。
- 保存时过滤不符合规则的选择，避免生成非法故障槽位。

## 变量规则

按故障设置变量的 `role` 判断允许层级：

- `parameter`：只显示并保存 `physical`。
- `input`：只显示并保存 `electrical`、`protocol`。
- `output`：只显示并保存 `electrical`、`protocol`。
- `middle`：保持现状，仍使用原有层级集合。
- `protocol`：保持现状，仍使用原有层级集合。
- 未知角色：保持现状，仍使用原有层级集合。

## 界面行为

故障设置面板渲染变量行时，根据变量角色过滤该行可见层级。输入和输出变量行不再显示物理层选项；参数变量行不再显示电气层和协议层选项。

计数显示应按实际可见选项数量计算。例如一个参数、一个输入、一个输出共 5 个可见层级选项，而不是按 3 个变量乘以 3 层计算 9 个。

## 保存行为

读取面板勾选时只读取实际存在的控件。为了兼容历史模型和旧 UI 状态，保存前还应按变量角色过滤一次声明结果：

- `physical` 中移除输入和输出变量。
- `electrical`、`protocol` 中移除参数变量。
- 中间量和其他角色不在本次规则中额外过滤。

过滤后再生成 `faultSlots`，同步到节点、模型包和能力映射。

## 非目标

- 不修改中间量的可选层级。
- 不修改分层故障绑定算法。
- 不修改故障库模型过滤。
- 不修改连线故障槽位规则。
- 不修改已存在故障实例的运行时语义，只在保存槽位时通过现有失效逻辑处理被移除的槽位。

## 测试范围

- `faultSlotPanelSchema` 渲染时按变量角色显示允许层级，并按可见选项计算总数。
- 属性面板中参数变量只生成物理层槽位。
- 属性面板中输入、输出变量只生成电气层和协议层槽位。
- 历史声明中输入/输出的物理层选择、参数的电气/协议层选择在保存后被过滤。
- 中间量现有行为保持不变。
