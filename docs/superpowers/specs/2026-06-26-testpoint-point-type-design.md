# 测点类型属性设计

## 背景

故障注入平台的测点设置需要为每个测点新增一个属性，用于在“物理测点”和“虚拟测点”之间选择。当前阶段该属性只用于测点配置界面展示和保存，不参与故障诊断、D 矩阵、测点启用规则或仿真计算。

## 目标

- 在测点配置界面新增测点类型选择项。
- 支持两个选项：物理测点、虚拟测点。
- 将选择结果保存到测点对象，后续功能可以复用该字段。
- 旧测点数据没有该字段时按物理测点处理。
- 不改变现有测点检测、安装、删除、D 矩阵生成和故障候选匹配行为。

## 数据设计

在测点对象上新增字段 `pointType`。

字段取值：

- `physical`：物理测点。
- `virtual`：虚拟测点。

默认值为 `physical`。保存时如果用户没有显式选择，也写入或归一化为 `physical`。展示时如果历史数据缺少 `pointType`，按 `physical` 显示。

## 界面设计

测点设置表单新增一个“测点类型”控件，放在“测点名称”附近，使用二选一控件或下拉框均可，具体样式沿用现有属性面板控件风格。

固定测点列表或测点卡片展示类型标签：

- `physical` 显示为“物理测点”。
- `virtual` 显示为“虚拟测点”。

该标签只作为元数据显示，不改变测点是否可启用、是否可检测或是否进入 D 矩阵。

## 保存与兼容

新增测点时默认 `pointType: 'physical'`。编辑已有测点并保存时，读取界面选择并写回 `pointType`。旧数据中缺失或非法的 `pointType` 统一归一为 `physical`，避免破坏历史模型包和手动测点。

## 测试范围

- 新增或更新测点时能够保存 `pointType`。
- 缺失或非法 `pointType` 时默认显示和保存为物理测点。
- 测点设置界面包含“测点类型”“物理测点”“虚拟测点”。
- 现有诊断测试、D 矩阵测试和测点工作台契约不因该字段变化而改变。

## 非目标

- 不根据物理/虚拟类型过滤测点。
- 不修改故障检测算法。
- 不修改 D 矩阵生成逻辑。
- 不为物理测点或虚拟测点增加不同图标、颜色或权限。
