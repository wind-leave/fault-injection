# 故障注入平台运行环境离线安装说明（Windows 10 x64）

本目录适用于 64 位（x64）Windows 10/11 电脑。安装前可按 `SHA256SUMS.txt` 校验文件完整性。

## 1. 安装 Node.js

双击运行 `node-v24.18.0-x64.msi`，使用默认选项完成安装。该版本为 Node.js LTS，满足平台要求的 Node.js 20 或更高版本。

## 2. 安装 Python

双击运行 `python-3.13.14-amd64.exe`。在安装界面勾选 **Add python.exe to PATH**，再选择“Install Now”完成安装。

## 3. 安装 uv

`uv-0.11.13-x86_64-pc-windows-msvc.zip` 是 uv 官方的便携包，不需要传统安装程序：

1. 解压 ZIP。解压目录可自行设置；建议使用固定、全英文、无空格的目录，例如 `C:\Tools\uv`。仅供当前用户使用时，也可使用 `C:\Users\你的用户名\Tools\uv`。
2. 确认该目录直接包含 `uv.exe`、`uvx.exe` 和 `uvw.exe`。
3. 打开“系统属性 -> 高级 -> 环境变量”，编辑用户或系统的 `Path`，新增 uv 所在的**目录**，例如 `C:\Tools\uv`。不要把 `uv.exe` 文件本身加入 `Path`。
4. 若由管理员为所有用户统一安装，建议添加到系统 `Path`；若仅当前用户使用，添加到用户 `Path` 即可。
5. 关闭并重新打开 PowerShell。

环境变量配置完成后，不需要再次运行安装程序。执行以下命令即可验证：

```powershell
uv --version
```

若输出类似 `uv 0.11.13`，即表示 uv 安装成功。

## 4. 验证安装

重新打开 PowerShell，执行：

```powershell
node --version
npm.cmd --version
py --version
uv --version
```

四条命令均输出版本号即安装成功。PowerShell 可能阻止 `npm.ps1`，故平台命令统一使用 `npm.cmd`。

## 5. 启动平台

将完整的“故障注入”项目文件夹复制到目标电脑，双击项目根目录中的 `启动故障注入平台.cmd`。

首次运行时，脚本会执行 `npm.cmd ci` 安装前端依赖，因此需要网络可访问 npm 软件源。若目标机完全离线，请将构建机上的 `node_modules` 目录与项目一并复制；脚本检测到该目录后会跳过依赖安装。
