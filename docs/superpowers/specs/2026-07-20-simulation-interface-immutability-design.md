# 仿真组件接口不可修改设计

## 目标

故障注入平台中的仿真组件一旦创建或绑定 Python 接口后，其接口定义必须保持不变。锁定范围包括组件名称，以及输入、输出和中间变量端口的名称、数据类型和数量。

系统信号、测量仪器及其他组件继续沿用现有属性编辑能力，不在本次改动范围内。

## 方案

采用界面与数据处理双层锁定。

属性面板把仿真组件的组件名称、端口名称、端口类型和端口数量显示为只读信息，不渲染可输入、可选择或可同步修改接口的控件。接口以外的既有可编辑配置继续保留。

保存属性时，仿真组件的读面板逻辑不再从 DOM 收集组件名称或端口定义；只提交允许修改的非接口字段。应用属性时保留现有组件名称、`inputs`、`outputs` 与 `middleVars`，避免调用方提交的属性值覆盖接口定义。

导入或恢复工作区快照时，已有仿真组件的接口定义不因导入数据被覆盖。对于新导入的仿真组件，导入包内的接口定义作为其初始、固定接口；导入完成后进入同一只读和保存保护路径。

## 数据流

```text
仿真组件初始定义（创建 / Python 绑定 / 新导入）
  -> 固定的 name、inputs、outputs、middleVars
  -> 只读属性面板
  -> 保存时忽略接口字段
  -> 导入/恢复时保留已有组件接口
```

## 错误处理与兼容性

旧工作区快照和模型包仍可正常加载。锁定不会删除已有字段，也不会改变端口连接或 Python 运行时的接口读取方式。若导入数据试图覆盖已存在仿真组件的接口，只接受非接口字段。

## 测试

测试覆盖未绑定和 Python 已绑定仿真组件：属性面板不提供可编辑接口控件；读取保存值不包含接口字段；尝试通过保存或导入覆盖接口后，名称、端口名称、类型和数量均保持原值。

回归测试确认系统信号和测量仪器的名称及端口编辑控件、保存行为不变。
