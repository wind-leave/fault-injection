# 将 JS 显控台配置转换为运行时 JSON

脚本：`tools/convert_display_console_config.mjs`。可读取其他版本的 `displayConsoleConfig.js`，生成当前平台支持的完整 `display-console.json`，无需手动删除注释、修改引号或复制配置。

在有 Node.js 和本项目依赖的开发机上运行。项目依赖尚未安装时，先执行 `npm ci`；已有 `node_modules/` 时无需再次安装。转换完成后只需把 JSON 复制到 Docker 部署的配置目录，目标机器不需要为转换脚本安装 Node.js。

## 1. 转换其他版本

在 PowerShell 7 中运行：

```powershell
Set-Location 'D:\项目方案\故障注入'
node tools/convert_display_console_config.mjs --input 'D:\旧版平台\src\constants\displayConsoleConfig.js'
```

默认生成到本项目的 `output/display-console.json`，不会直接替换当前部署配置。脚本会报告输入元素数、列数和显控台数量。输入路径支持中文、空格，建议始终加引号。

不提供 `--input` 时转换本项目当前的 `src/constants/displayConsoleConfig.js`：

```powershell
npm.cmd run convert:display-console
```

也可以在任何工作目录使用脚本的绝对路径。默认输入、输出均相对脚本所在项目；手动提供的相对路径则相对当前终端目录。

## 2. 指定输出、检查和更新部署

指定其他输出位置：

```powershell
node tools/convert_display_console_config.mjs --input 'D:\旧版平台\src\constants\displayConsoleConfig.js' --output 'D:\部署包\public\config\display-console.json'
```

只检查是否能转换及配置是否合法，不写入文件：

```powershell
node tools/convert_display_console_config.mjs --input 'D:\旧版平台\src\constants\displayConsoleConfig.js' --check
```

将其他版本的配置直接更新到本项目的外部配置文件：

```powershell
node tools/convert_display_console_config.mjs --input 'D:\旧版平台\src\constants\displayConsoleConfig.js' --output public/config/display-console.json --overwrite
```

如果 Docker 挂载的是这份 `public/config/`，刷新浏览器即可生效；如果 `.env` 的 `GZ_DISPLAY_CONFIG_DIR` 指向其他目录，将生成文件放到那个目录。转换本身不需要重新构建或重启容器，前提是镜像已包含四部分配置的运行时加载功能。

## 3. 提取内容及支持范围

源 JS 必须导出以下四项数据，脚本会逐一保留，不从当前版本自动补齐缺失项：

| 导出名称 | 转换后的内容 |
| --- | --- |
| `DISPLAY_CONSOLE_INPUTS` | 输入元素、名称、单位、显示比例、自动测点设置 |
| `DISPLAY_CONSOLE_VECTOR_PORT_ID` | 默认输入端口 ID |
| `DISPLAY_CONSOLE_COLUMNS` | 公共列数量、顺序、标题和数据来源 |
| `DISPLAY_CONSOLE_PRESETS` | 所有显控台的输入覆盖、列覆盖、端口、控制对象、参数和共享绑定 |

支持 `export const` / `export let` / `export var` 和 `export { localName as DISPLAY_CONSOLE_... }`。支持注释、单引号、尾随逗号、UTF-8 BOM、科学计数法、普通对象与数组、本文件中的静态变量引用、属性读取、数组/对象展开、简单算术及模板字符串。

函数和导入语句可以保留，脚本不会执行它们，也不会写入 JSON。通过函数调用、`Array.from()`、`.map()` 等动态构造配置，或者在顶层通过赋值、`Object.assign()` 修改配置的版本，需要先将数据整理为静态声明；遇到这些写法，脚本会报错，不会猜测结果。脚本不是将任意 JavaScript 程序完整执行后导出的工具。

生成前使用与前端相同的结构校验，包括公共字段、向量索引、端口 ID、受控参数列表和共享绑定格式。组件类型及参数是否真实存在，仍取决于目标平台安装的组件。

## 4. 文件更新规则

- 源 JS 始终只读。
- 输出文件不存在时会创建父目录并生成 UTF-8 JSON。
- 输出内容相同时返回“内容一致，无需更新”。
- 输出内容不同时，添加 `--overwrite` 才会替换。
- 解析或校验失败时返回非零退出码，保留已有输出文件。
- 不允许将源文件自身作为输出，不允许输出到符号链接或目录。

参数完整说明：

```powershell
node tools/convert_display_console_config.mjs --help
```
