# 实践会话私有输入补充设计

## 目标

创建实践会话时，除仿真模型、D 矩阵和目标故障外，同时接收导出包中的 `initialRecommendedPath` 与 `keyNodes`，并作为后端私有任务数据保存和使用。

## 接口

`POST /api/practice/session` 新增两个可选字段：

- `initialRecommendedPath`：对象，提供时替代后端根据 D 矩阵自动生成的初始推荐路径。
- `keyNodes`：数组，提供时替代后端根据 D 矩阵自动生成的故障树关键节点。

字段缺省时继续使用现有自动生成逻辑，保证旧客户端兼容。显式传入空对象或空数组视为调用方提供的任务私有数据。

## 数据流与保密边界

服务端创建 `PracticeSession` 时把两项数据复制到会话内部的 `initial_best_path` 和 `fault_tree_key_nodes`。后续路径评分使用这些会话内部值。创建响应和状态响应不新增这两个字段，避免提前向三维端公开标准路径和关键节点；提交后的既有评分响应行为保持不变。

## 测试

接口回归测试创建带自定义路径和关键节点的会话，验证后端会话使用输入值，同时验证创建响应不包含这些私有数据。现有未传字段的测试继续覆盖自动生成兼容路径。
